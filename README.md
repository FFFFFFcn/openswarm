# 蜂群引力AI — 你的小红书智能体编辑部

**一个人，就是一支内容团队。**

蜂群引力AI 是一款自研的小红书内容运营桌面应用。它把一个主理人智能体和四位专家智能体（起号策划、账号对标分析、选题策划、内容创作）装进你的电脑：你只需要在对话里说出想法，团队会自动拆解任务、检索数据、产出策略与内容，最终沉淀为可执行的账号资产——而不是一堆聊天记录。

## 核心能力

### 🧭 主理人 + 四位专家，像真实编辑部一样协作
向主理人下达一句话任务，它会自动编排团队：起号策划给出账号定位与增长策略，选题策划持续产出选题，内容创作完成图文初稿，账号对标分析帮你找到值得学习的同行。全过程可视、可干预、可追溯。

### 🔥 爆款洞察
一键检索近 30 天同赛道高互动笔记，自研数据引擎自动聚合分析，输出 TOP10 爆款拆解与精美 HTML 报告，让选题永远踩在流量脉搏上。

### 🎯 账号对标
按账号或按赛道、粉丝区间、账号等级智能筛选：同阶对标看打法、高阶标杆学路径、KOL 候选做初筛，附近 7/30 天互动趋势、内容特点与代表作分析。

### 🎨 AI 封面设计
基于实时爆款封面数据，分析同赛道封面视觉规律，一次生成三种差异化封面设计方案，附可直接使用的生图提示词（适配 3:4 竖版）。

### 📋 选题看板 + 编辑部工作流
选题从提出到批准、草稿从创作到发布标记，全流程状态化管理。智能体产出的每一份策略、选题和草稿都会自动归档，重要动作必须经过你的确认——AI 提效，人做决策。

### 🛡️ 合规预检
内置高风险表达扫描与人工核验清单，发布前多一道保险。

## 适合谁

- **个人创作者 / 博主**：没有团队，也想拥有专业编辑部的产出效率
- **主理人 / 小商家**：用内容为生意引流，但没时间钻研平台玩法
- **MCN / 代运营从业者**：批量管理账号定位、选题与内容生产流程

## 下载与安装

1. 前往 [Releases](https://github.com/FFFFFFcn/openswarm/releases) 页面下载最新版 Windows 安装包
2. 双击安装，首次启动输入邀请码激活
3. 在“模型设置”中配置你的大模型凭据，在管理后台配置数据接口密钥
4. 填写账号底稿，开始向主理人下达第一个任务

## 数据与隐私

- 所有账号资料、策略、选题、草稿仅保存在你的本机，不上传任何服务器
- 模型凭据与接口密钥仅存储在本地，浏览器与日志中不出现明文
- 应用默认只监听本机地址，不对外网开放
