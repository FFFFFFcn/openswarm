# 爆款洞察分析技能

## 可用工具
- search_xiaohongshu_hot_notes: 查询近 1-30 天小红书爆款笔记并生成 HTML 报告
- analyze_xiaohongshu_titles: 基于趋势样本生成 10 个标题(generate)，或对标题进行六维评分(score)
- design_xiaohongshu_cover: 获取同赛道爆款封面数据，输出差异化封面设计方案

## 操作流程

### 爆款笔记搜索
1. 确认关键词和时间范围（days 参数，最大 30）
2. 调用 search_xiaohongshu_hot_notes
3. 工具返回 requires_confirmation 时，用 TeamSay 汇报主理人让用户选择细分方向，不得自行继续
4. 用户确认后，设置 broad_keyword_confirmed=true 重新调用

### 标题生成或评分
1. 确认 mode（generate 或 score）和关键词
2. generate 模式：调用后输出 10 个标题 + 样本匹配指数 + 参考链接与互动量
3. score 模式：调用后输出六维原始分/权重/加权分 + 三种适用场景明确的改写

### 封面设计素材
1. 确认关键词和时间范围
2. 调用 design_xiaohongshu_cover 获取同赛道爆款封面数据
3. 结合用户需求与爆款风格输出三种差异化封面设计方案
4. 每种方案含生图提示词，适配 3:4 竖版 1080x1440

## 输出规范
- 爆款搜索：如实报告四类样本数量，低样本时给出警告
- 标题生成：样本匹配指数、参考链接与互动量
- 标题评分：六维原始分/权重/加权分 + 三种改写
- 封面设计：三种差异化方案 + 生图提示词（3:4 竖版 1080x1440）
- 所有任务：汇报 HTML 报告位置（如有）

## 错误处理
- 工具返回错误时最多重试一次，仍失败则如实报告错误并结束
- 不得反复重试

## 完成汇报
完成后用 TeamSay 向主理人汇报：
- 查询条件
- 关键结论
- HTML 报告位置
- 仍需人工核验项

## 禁止事项
- 不得用联网搜索、常识或猜测伪造样本
- 用户拒绝后不得重试同一调用、不得换参数绕过、不得改用其他工具取数
- 用 TeamSay 向主理人报告"用户已拒绝该数据调用，任务终止"后结束本轮回复
